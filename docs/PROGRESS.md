- Ветка: codex/t005a-host-launch от origin/main (d06f19d).
- `npm run build` готовит приложения; `npm start` запускает один сервер,
  раздающий собранный клиент на http://127.0.0.1:3001/ и обслуживающий
  same-origin HTTP/WebSocket без Vite. PORT меняет адрес игры и endpoint вместе.
- HTML и JS/CSS сборки загружаются при старте относительно серверного модуля.
  GET/HEAD имеют MIME types, no-store и nosniff. Раздаются только известные
  файлы; исходники, source maps и символьные ссылки внутри assets исключены.
  Отсутствие сборки завершает запуск до открытия порта с подсказкой npm run build.
- Solo остаётся на loopback с проверками Host/Origin. По умолчанию production
  разрешает origin сервера; CLIENT_ORIGIN добавляет проверенный loopback origin.
  Dev запускается с --dev без dist; Vite dev/preview proxy сохранены.
- WASD и серверный шаг 20 Гц, правила управления одним solo-персонажем,
  reload/retry и sequence/ack сохранены. Движение показывается по серверным snapshots.
- Локальный npm run check прошёл: форматирование, lint, типы, граф импортов,
  шесть сборок, 42 unit + 17 tooling + 12 контрактных + 16 smoke-тестов
  (87 без skipped). Проверены прямое подключение без Vite, WASD и reload,
  HTTP GET/HEAD/TRACE, Host/Origin, недоступность исходников и обходов пути.
- Дополнительно проверены production/dev, нестандартный PORT, стандартные Origin,
  health и SIGTERM. Большие статические ответы завершаются напрямую Node HTTP:
  адаптер Colyseus оставлял ответ открытым после backpressure, что мешало reload.
  Библиотеки не менялись. Markdown-ссылки и git diff --check проверены.
- Публикация PR и проверка CI — следующий шаг текущей задачи.
- Runtime: Node.js 24.19.0 (.nvmrc), npm. Chromium установлен в игнорируемый
  .cache/playwright; локальные браузерные проверки используют PLAYWRIGHT_BROWSERS_PATH.
- Ограничения: отдельная build перед первым запуском и после изменения исходников;

  столкновений, спринта, чанков, друзей, TLS и сохранений. Мир теряется при остановке.
