- T010 — скрытность: IN_PROGRESS. Ветка codex/t010-stealth от origin/main
  (6d06a98); дерево до задачи чистое. Пользователь поручил слияние PR после
  успешных проверок финального коммита. Следующую задачу в этом запуске не начинать.
- Обе клавиши Ctrl задают скрытность для WASD и цели мышью, сразу обновляют
  предсказание; смена Ctrl/Shift сохраняет цель. Ctrl имеет приоритет над Shift:
  2 м/с и восстановление запаса 0.1/с, независимо от истощения. Диагонали,
  точное прибытие и столкновения сохранены. В покое Ctrl поддерживается 10 Гц.
- Общий шаг задаёт шум движения: скрытность 2 м, ходьба 8 м, спринт 16 м;
  покой, достигнутая цель и полная блокировка стеной дают ноль. Сервер вычисляет
  режим/шум, клиент предсказывает их общими правилами. HTML HUD показывает
  режим, радиус и запас; Phaser приседает своего и остальных персонажей.
- Протокол v5 требует boolean isSneaking в обоих видах команд и isSneaking/
  noiseRadiusMeters в состоянии каждого персонажа. Старые версии отклоняются;
  клиент и сервер нужно пересобирать и перезапускать вместе. Модификаторы
  API передаются именованным объектом. Поддельные клиентские шум/скорость игнорируются.
- Blur/hidden/disconnect/dispose очищают обе Ctrl, Shift и движение. Сервер
  снимает режим при потере контроллера или 10 шагах без свежего ввода; неактивная
  вкладка не останавливает чужого контроллера. Reload не возобновляет ввод.
- Полный npm run check прошёл: форматирование, lint, типы, граф, шесть сборок
  и 215 тестов без skipped: 156 unit + 17 tooling + 16 контрактных + 26 smoke.
  Chromium проверил скорость/шум по серверным ticks, Ctrl+Shift/Ctrl+WASD,
  Ctrl+клик, idle heartbeat, blur/reload. Прежние регрессии движения/кооператива
  прошли; свежий .cache/t010-stealth.png осмотрен, в Git не добавлен.
  Unit также проверяют полную блокировку стеной, смену владельца ввода,
  предсказание/ack и сохранение серверного режима в неуправляющей вкладке.
  Для локального запуска использованы Node 24.19.0 и кэш Chromium
  PLAYWRIGHT_BROWSERS_PATH=.cache/playwright, с разрешением на локальные порты.
- Ограничения: баланс начальный; радиус пока не вызывает реакцию AI и не
  создаёт аудио. Нет распространения шума через стены, поиска пути, боя и
  сохранений на диск. Предсказание ограничено 500 мс, коррекции прямые.
- После слияния T010 — T011 (один процедурный чанк), отдельным запуском.
