# Приёмка одиночного прототипа — T014

Дата: 25 октября 2026 года. Основа: T012 и T013 слиты в main (398e69b).
Требования: [GAME_DESIGN.md](../GAME_DESIGN.md), одиночная часть этапа 1.
Кооперативная приёмка вынесена в T014C и остаётся PAUSED; весь этап 1 с кооперативом
не объявляется завершённым.

## Среда и воспроизведение

Проверяется production-сборка Phaser/Vite и Node/Colyseus, HTTP и WebSocket
на loopback одного компьютера. Node.js 24.19.0 из `.nvmrc`, npm workspace,
Chromium из Playwright 1.64.0. Локальный запуск — macOS; CI Quality — Ubuntu.
Клиент и сервер собраны вместе, wire-протокол v5, генератор v1, SQLite-схема v1.

```sh
npm ci
npx playwright install chromium
npm run check
```

Если Chromium установлен в `.cache/playwright`, перед командами задайте
`PLAYWRIGHT_BROWSERS_PATH=.cache/playwright`.
Отдельная проверка сквозной приёмки после `npm run build`:

```sh
npm run test:smoke -- tests/smoke/solo-persistence.spec.mjs
```

Тест запускает реальный собранный сервер, который раздаёт клиент с same-origin.
SQLite создаётся во временном каталоге; игровой `.local/solo.sqlite` не открывается.
Все процессы и временные файлы освобождаются в `finally`. Фиксированные порты
3109/3110 и порты общего Playwright-конфига должны быть свободны.
Ожидания опираются на статус, подтверждённые координаты и tick, без `sleep`.

## Ограничения принятого прототипа

- Это solo-срез технического прототипа. Нет лута/инвентаря, зомби, боя, здоровья
  и игрового цикла выживания. Следующая карточка — T015; в T014 она не реализуется.
- Нет автоматического поиска пути: цель за стеной остаётся активной до отмены;
  обход выполняется вручную. Прицел визуальный, без стрельбы; шум пока не влияет на AI.
- Terrain декоративный; коллизии статические, между персонажами столкновений нет.
  Мир — повторяемые руины/камни v1, без дорог, регионов и сохранения изменений чанков.
- Только solo сохраняет ID/позицию и ключ генератора. Stamina/ввод/ack при запуске
  сбрасываются. После аварии возможен откат до последнего commit: обычно до секунды,
  при задержке event loop — дольше. Синхронный SQLite fsync может задержать симуляцию.
  Миграции, автоматические бэкапы и измерения дисковой задержки отложены.
- Клиент и сервер требуют совместной сборки. При сетевой задержке возможны видимые
  коррекции; без snapshots предсказание замирает через 0.5 секунды. Это не оценка FPS
  или субъективной отзывчивости на разных компьютерах.
- Проверены автоматизированные сценарии Chromium на одном компьютере и отдельные
  серверные процессы. Другие браузеры, реальные устройства, длительная игра,
  сон/пробуждение ОС, дефицит ресурсов и нагрузка не проверялись.
- Существующие кооперативные регрессии остаются в полном наборе тестов, но не
  подтверждают LAN/интернет-приёмку. T005C/T014C остаются PAUSED; Tailscale не нужен.

Для обычного запуска и работы с сохранением используйте [README](../README.md).
