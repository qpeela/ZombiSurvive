# ZombiSurvive

Браузерная 2D-игра о выживании в мире с зомби. Браузер подключается к локальному
миру через Colyseus/WebSocket и показывает стартовую позицию. Сцена Phaser пока
пустая: движение и игровые механики ещё не реализованы.
Целевая модель — одиночная игра и кооператив с друзьями, локальный сервер
на компьютере игрока-хоста без аренды выделенного сервера. Подключение друзей
пока не реализовано. Требования: [ADR 0001](docs/adr/0001-local-host-coop.md).

## Установка и запуск

Использовать Node.js из .nvmrc и npm. С nvm:

```sh
nvm install
nvm use
npm ci
npm run dev
```

Клиент: http://127.0.0.1:5173. Проверка сервера: http://127.0.0.1:3001/health.
Оба процесса запускаются вместе и завершаются по Ctrl+C.
Только локальный доступ на 127.0.0.1; публикация в интернете не настроена.
После запуска над canvas появляется статус подключения и стартовая позиция (0, 0 м).
Перезагрузка страницы и повторный вход возвращают того же solo-персонажа в тот же мир.
Несколько локальных вкладок представляют одного игрока. После остановки сервера
мир и ID теряются: сохранение на диске появится в T013.

Отдельный запуск: npm run dev --workspace @zombi-survive/client или
npm run dev --workspace @zombi-survive/server. Порт сервера задаётся через PORT.
При изменении порта сервера задайте его адрес в GAME_SERVER_URL для Vite.
Клиент получает игровой endpoint от origin страницы, Vite проксирует HTTP matchmaking
и WebSocket на локальный сервер. GAME_SERVER_URL используется только конфигурацией
Vite, а не кодом браузера. Сервер проверяет Host и Origin; CLIENT_ORIGIN задаёт
разрешённый адрес клиента (по умолчанию http://127.0.0.1:5173).
Для нестандартных портов:

```sh
PORT=3002 GAME_SERVER_URL=http://127.0.0.1:3002 npm run dev
```

При потере связи UI сообщает об этом. После восстановления хоста нажмите
«Подключиться снова». Подключение ограничено тайм-аутом 10 секунд;
автоматическое восстановление связи пока не реализовано.

## Проверки

Установить Chromium для smoke-тестов один раз, затем выполнить общий набор:

```sh
npx playwright install chromium
npm run check
```

Отдельные команды:

```sh
npm run format
npm run format:check
npm run lint
npm run typecheck
npm run architecture:check
npm run build
npm test
```

Smoke-тесты требуют актуальной сборки: npm run build перед npm run test:smoke.
Общий npm run check делает это автоматически. Тесты используют отдельные порты
4173, 3101 и 3102, запускают собственные приложения и не переиспользуют чужие процессы.
Если порты заняты, освободить их или согласованно поменять playwright.config.mjs.

GitHub Actions устанавливает зависимости и Chromium и выполняет npm run check:
форматирование, lint, типы, архитектуру, сборки, тесты ограничений, контракты
движения и smoke-тесты. Отдельный запуск контрактных тестов после сборки:
`npm run test:contracts`. Корневые build/lint/typecheck собирают общие пакеты первыми;
перед отдельным typecheck приложения выполнить `npm run build:contracts`.

## Проверка собранных приложений

```sh
npm run build
CLIENT_ORIGIN=http://127.0.0.1:4173 npm run start --workspace @zombi-survive/server
```

В другом терминале: npm run preview --workspace @zombi-survive/client,
затем открыть http://127.0.0.1:4173. Vite preview предназначен для локальной
проверки сборки; production-хостинг ещё не настроен.

Phaser включён в локальный bundle, сторонние графические ассеты не используются.
Текущий bundle клиента с Phaser и Colyseus около 410 kB gzip; Vite сообщает о chunk больше 500 kB
без сжатия. Оптимизацию загрузки выполняем отдельно после появления игрового контента.
